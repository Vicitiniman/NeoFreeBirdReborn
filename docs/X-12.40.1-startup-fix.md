# X 12.40.1 startup correction — beta 70

The first device test of beta 69 reported an indefinite bird launch screen on an iPhone 16 Pro Max running iOS 27.0.1. The previous static audit, native helper tests and tweak compilation had passed; they did not establish that the app could finish launching.

## Defect and correction

The new `T1TabView` label adapter refreshed its label from inside `layoutSubviews`. With **Tab labels** off, no label had been allocated. Objective-C reads `nil.hidden` as false, so comparing it to the desired hidden state repeatedly called `setNeedsLayout` on the tab. Every layout requested another layout, a concrete startup regression consistent with the reported freeze.

The adapter now returns immediately when labels are off and no label exists. A retained label is hidden once when the setting is switched off, then left idle. Hidden labels skip color/selection work. A visible label already at the front is no longer reordered on every pass. Native icon layout, custom Likes titles and the classic launch animation remain available.

No login, saved-session, account-removal or cache code was changed. This update does not require clearing account data.

## Regression checks

The macOS Foundation runner compiles the production adapter against small view fixtures that coalesce layout requests. It checks:

- Startup with labels off settles in one pass, with no label allocation or repeated invalidation over 100 refreshes.
- Visible labels settle, preserve selection colors and custom Likes titles, and do not accumulate icon shifts.
- Labels survive off/on transitions and empty/native titles without a loop.
- New native subviews cause one reorder; subsequent layout stays idle.
- Wide tabs retain their horizontal title placement.

The fixtures check layout scheduling and adapter behavior; they do not simulate an iOS launch or run UIKit. Existing source, Python, JavaScript, Swift and native regression checks and arm64 tweak compilation run in [PR validation](https://github.com/Vicitiniman/NeoFreeBirdReborn/pull/49/checks).

Confirmation that beta 70 reaches the timeline on the affected iPhone remains a device check. An IPA was not built for this fix.
