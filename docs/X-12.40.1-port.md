# X 12.40.1 compatibility port — beta 69

Implementation report, November 4, 2026. Based on beta 68 and the supplied decrypted X 12.40.1 build 1 IPA. This is a native tweak update; the separate Safari userscript was not modified.

**Device follow-up:** beta 69 froze on the bird launch screen in the user's first iPhone test. Beta 70 corrects a repeated-layout defect in the new tab label adapter and adds scheduling regressions. See [the startup correction report](X-12.40.1-startup-fix.md). The interface audit below remains valid, but does not prove a successful device launch.

## Result

The port replaces or retires all 11 newly missing hook declarations from the audit. The updated read-only inventory has **250 native targets present, 42 system-runtime hooks, 9 intentional new methods, 2 guarded alternatives and 5 guarded legacy aliases: 308 declarations total, zero unguarded missing targets**. The three sidebar setter exports are present. This establishes interface coverage, not successful execution of every feature on an iPhone or iPad.

## Changes

- **Sign-in and session restoration:** a single exact-version/build gate now covers setup, account attachment, network requests, in-app cookies, replies and diagnostics. Existing Keychain sessions are preserved. No password handling, account verification bypass or third-party credential transfer was added.
- **Logout:** retargeted `removeAccount:source:withAccountRemovalCompletionHandler:` and verified its argument signature before installing the hook. It still forgets only the explicitly removed account.
- **Likes:** re-traced the native factory and Bookmarks allocation/initializer path. The switch now uses **16-bit** entries, not the old byte table. Updated offsets, image UUID and full instruction checks are kept together in a contract header; unknown images fail closed.
- **Navigation labels/themes:** removed calls to the vanished `titleLabel`, `_t1_updateTitleLabel` and `showsTitleInDisplayMode:` APIs. Labels are now owned by the tweak; native icon/badge layout adjustments are reversible. Settings and Likes title refresh use the same helper.
- **Filters:** one model resolver recognizes the renamed `URTTimelineStatusItemViewModel` and the older alias. Keywords/@mentions, the nested ad fallback, Topic context and optional sensitive-warning hook use the current model. The warning hook also checks its runtime signature.
- **iPad chrome:** moved branding hooks to surviving split/navigation owners, bounded the rail search, excluded avatars/navigation icons, retained a Home bird when no branded rail is found, and selected the native image title instead of the newer animated-X logo host while bird branding is enabled. Removed the obsolete trends-controller hook; Explore hiding survives and dedicated runtime sidebar children are discovered within current navigation owners.
- **Grok:** added current Imagine CTA/render/image-generation/transfer gates. Analytics placement names were not treated as Boolean switches.
- **Uploads/downloads:** 4K preference now uses surviving native resolution getters and preserves higher native limits/network choices. Removed the obsolete cache-enabling hook; downloads continue through the existing direct media-URL path.
- **Video player:** resolved panning/chrome fields by name instead of incorrect fixed indexes; corrected the Swift lazy gesture field lookup.
- **Home tabs:** live add-tab hiding now updates known Home containers even without a pinned repository, supports native bar items and restores prior UI state.
- **DM badges:** replaced the removed DM user hook with the current XChat sender adapter. Diagnostics, wording and build checks were updated.

## Navigation and unavailable options

**Classic navigation** is a new option under Appearance and navigation, enabled by default. X now includes a separate glass-navigation/router pipeline. The supported custom tab integration stays on the familiar native entry-based path. Opting out restores X's own layout decision; equivalent custom-tab behavior in the glass pipeline has not been established. Reopen the app after changing this option.

Four old switches have no verified replacement in this host: **Voice posts and replies, No voice messages, Old message compose bar, and Reply later in DMs**. They are visibly unavailable and return an effective off value. Saved values are retained for a future implementation. These features were not falsely labeled fixed.

The concrete iPad trends host disappeared from the IPA. Its replacement hierarchy has not been observed on a device. The new bounded owner discovery is a safe fallback; it does not justify claiming that every possible right-sidebar layout has been confirmed hidden.
