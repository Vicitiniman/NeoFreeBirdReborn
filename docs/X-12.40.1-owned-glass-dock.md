# Custom glass dock, post surfaces and Listen Live — beta 74

The dock geometry and generic post-plane treatment below are superseded by [beta 75](X-12.40.1-collapsing-glass-and-theme.md), which widens/minimizes the tray and removes plane mutation to preserve media. Listen Live behavior remains unchanged.

The supplied screenshots show a quoted post card and the opened conversation's focal post retaining black backgrounds while the surrounding interface is themed. They also show the beta 73 navigation effect covering the avatar/bird header. The requested replacement is an owned navigation control, rather than another background applied to X's bar.

## Custom dock

**Appearance → Liquid Glass design** now selects NeoFreeBird's own dock. The phone uses a compact centered capsule; the iPad uses a vertical dock. Controls use consistent SF Symbols, native unread counts/dots, optional captions from Tab labels, press feedback and a spring selection lens. Larger custom tab sets scroll so touch targets remain at least 44 points. Materials use UIKit's public clear-glass factory when available, with an ultra-thin blur fallback; custom rim, sheen and selection layers define the appearance. Reduce Transparency and Reduce Motion remain respected.

The native tabs stay retained as navigation destinations. A tap resolves the original tab's identity in the current array, then calls the verified `TFNCustomTabBar -_selectTabAtIndex:sendControlAction:` entry point. This updates native selection before its delegate action, and forwards repeat taps. Long presses use the verified native delegate with the original source view. Stale views after account/snapshot replacement are rejected. A missing/changed native callback leaves stock navigation available. Native frames remain owned by X; the replacement dock is attached to the navigation container above content. Native hiding/collapse and opacity are respected. Badge/icon updates are coalesced per owner.

The design keeps the verified entry/delegate navigation pipeline instead of enabling X's glass rollout. The full-header effect is removed, leaving the avatar, bird, back button and actions accessible. Fully reopen X after installing or changing the navigation design. Disabling the option removes the owned controls and restores the saved native backgrounds/visibility. The Subscriptions sidebar editor from beta 73 remains available.

## Theme consistency

Current `T1QuotedStandardStatusView`, `T1ConversationFocalStatusView` and `T1StandardStatusView` surfaces receive the active palette background after native layout. Quote/focal composable background planes are handled separately, including `TFNSolidColorView`'s color setter. Discovery is bounded to 32 direct/composable candidates and excludes photos, video/text classes and plain content containers with children. There is no recursive media traversal or generic color replacement across the app. Main app/window and drawer hosting backgrounds follow the palette to cover safe-area gaps. Visible tracked surfaces update after a theme change.

## Listen Live

**Timelines → Hide Listen Live banner** is on by default. The current Listen Live label belongs to the live-audio strip managed by `T1FleetLineHeaderController`. Its native visibility decision is suppressed and its native visibility, expanded/active height and top-inset updates are requested when the setting changes. Existing Hide Spaces choices continue to apply. Manually opened audio playback is unaffected.

## Validation

Native regressions cover dock geometry, scrolling/minimum hit areas, real selection-before-delegate ordering, current native tab identity, reorder, repeat taps, long press, stale/account replacement and capability fallback. Post-plane policy tests exclude images/video/text and partial media regions. Live banner tests cover hide/restore, native height/inset updates and existing preferences. Existing layout/restoration, Swift navigation, filtering and session regressions remain enabled. The full iOS workflow compiles and links all UIKit/Logos code.

These are source/native model and build checks. Appearance, touch behavior, post rendering and live-strip removal on a physical iPhone/iPad still need device validation. New reports include `postSurfaceThemeRuntime`, `liveAudioBannerRuntime` and the custom dock's button/material state without post text or account identifiers. [PR validation](https://github.com/Vicitiniman/NeoFreeBirdReborn/pull/49/checks) records the build result.
