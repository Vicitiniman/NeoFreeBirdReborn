# Optional Liquid Glass design and Subscriptions — beta 73

The navigation treatment below is superseded by the [owned glass dock in beta 74](X-12.40.1-owned-glass-dock.md). Subscriptions controls remain unchanged.

The supplied beta 72 / `06802c3` report confirms that the current XSettings entry installed and opened. It also confirms that this account uses `T1TabbedAppNavigationViewController` and `T1TabBarViewController`; X's native glass controller was not observed. Leaving the server's navigation choice unchanged therefore retained the flat tab bar.

## Enable

Open **NeoFreeBird → Appearance → Navigation → Liquid Glass design**. It is off by default. Turning it on turns off Classic navigation, and turning Classic navigation on turns off this design. The material treatment updates immediately; fully close and reopen X to change its native navigation architecture. Turning the design off restores the saved native backgrounds and decorations; reopen X to restore X's own navigation rollout decision.

The option requests the current `ios_liquid_glass_redesign_enabled` and `ios_liquid_glass_redesign_quick_composer_enabled` switches only on the supported X 12.40.1 build with UIKit's native glass API present. It does not change account subscription state. The existing native-glass adapter continues to provide saved tab ordering, visibility, Likes and tweak settings when X constructs that controller.

The older navigation owner also receives a material treatment, so access to the design does not depend on a successful rollout switch. Its phone tab bar uses an inset glass capsule and selected-tab highlight; the iPad uses a rounded vertical rail. Known TFN navigation-bar backgrounds receive the same material. UIKit's public `UIGlassEffect` is resolved at runtime to retain the existing build SDK; earlier systems use `systemMaterial` blur. [Apple's UIKit guidance](https://developer.apple.com/videos/play/wwdc2025/284/) describes these system materials.

The treatment retains native tab views, badges, hit areas, ordering, navigation actions and deliberate bar hiding. It does not install competing tab gestures, move native tab frames, scan timeline views, or blur each post. Material updates are cached until appearance, settings or accessibility changes. Selected-tab motion respects Reduce Motion; Reduce Transparency uses an opaque surface, and Increase Contrast strengthens the outline and selection. Text and media remain on the content layer, following [Apple's navigation/material guidance](https://developer.apple.com/documentation/TechnologyOverviews/adopting-liquid-glass).

## Sidebar

**Appearance → Edit sidebar → Subscriptions** is now a separate selectable and reorderable tile from Premium/Blue. Recognized subscription icon names take priority over localized titles; Subscribe/Subscriptions titles cover native rows with newer icons. Existing saved selections stay authoritative, including hiding every managed item. The native rows and their actions are retained for restoration, and asynchronous sidebar rebuilds receive the same filtering. Unknown rows and the native Settings entry are preserved.

## Validation

Native regressions cover explicit glass/default/classic policies, an unavailable native API, conflicting imported preferences, phone/iPad/small-window geometry, repeated layouts, restoration of owned backgrounds and hidden decorations, newer native theme changes, localized Subscriptions, Premium isolation, reordering and asynchronous sidebar refresh. The iOS compile/link/package workflow validates UIKit and Logos code. These checks do not prove rendering or touch behavior on a physical iPhone/iPad; those remain device checks.

Compatibility exports include `liquidGlassDesignRuntime`: the enabled state, native API availability, accessibility policy, attached surfaces, dimensions and material/selection update counts. It exports no screen text or account identifiers. Build results are recorded in [PR validation](https://github.com/Vicitiniman/NeoFreeBirdReborn/pull/49/checks).
